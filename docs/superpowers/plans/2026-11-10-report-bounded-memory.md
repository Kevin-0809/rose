# 报表源数据有界内存改造计划

**目标：** 在独立 worktree 中消除三张比较源表的全量 Java 集合，保持当前全表范围和统计口径。

**架构：** 数据库执行分组、去重和排序；源查询使用关闭自动提交的 JDBC 游标。明细按问题键、流水号排序，Java 只保留一个问题代表记录和当前流水号计数。配置目录、字段映射仍可缓存。汇总只保留领域级计数，不持有原始交易、字段和响应码。

**范围边界：** 不增加日期过滤，不修改源表，不引入表结构迁移；不承诺消除所有台账、Excel 及数据库长事务风险。源表在生成过程中应保持稳定。

## 运行边界

数据库排序和分组仍需要数据库资源；游标事务在读取期间保持打开。JVM 内存应随 fetch 窗口、工作线程数和配置/领域规模变化，不再随三张源表原始行数线性增长。尚需实际 PostgreSQL 执行计划和生产规模压测。
