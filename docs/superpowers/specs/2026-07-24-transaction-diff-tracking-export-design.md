# 交易级差异问题跟踪文本导出设计

## 目标

在交易级差异页面新增独立的“导出问题跟踪表”操作。用户选择一个源批次后，系统从 `ana_tran_diff_result` 查询该批次的交易级差异，按服务码和双方响应码归一，生成可供下游采集的 UTF-8 文本文件，并将每条导出结果 1:1 写入新的导出流水表。

本期不导出 Excel，也不提供整改字段维护页面。

## 页面与接口

- 在 `/samples/transaction-diffs` 页面新增“导出问题跟踪表”按钮。
- 按钮提交当前的 `batchId` 至 `GET /samples/transaction-diffs/tracking-export`。
- `batchId` 是必填项。未填写时，页面显示“请选择批次后导出”，不请求下载接口。
- 接口仅以 `ana_tran_diff_result.batch_id = :batchId` 查询；不继承交易码、服务码、报文类型、负责人、流水号等其他页面筛选项。
- 响应为 `text/plain; charset=UTF-8`，下载文件名为 `trandiff_hf_{yyyyMMddHHmmss}.txt`。

## 归一与取值口径

原始数据仅来自 `ana_tran_diff_result`。每个源批次内按以下字段归一：

```text
service_code + orig_error_code + dest_error_code
```

每个归一组只导出一行：

- 流水号从该组任意选取一条 `sample_tran_seq_no`，不拼接。
- 不输出 `affected_tran_count`，也不进行影响条数汇总。
- 交易负责人严格取被选中原始行的 `owner`。
- 领域和交易名称通过 `ana_tran_catalog` 按 `tran_code + service_code` 左连接补充；未匹配时输出空值。
- 528 响应码/描述取 `orig_error_code` / `orig_error_desc`。
- CCBS 响应码/描述取 `dest_error_code` / `dest_error_desc`。
- 导出文件第一列为“业务日期”，每行写导出服务器当前自然日期，格式为 `yyyyMMdd`。
- 表内“批次”列保留源批次号；文件名中的时间戳代表本次导出批次。

## 文本格式

- 文件编码：UTF-8。
- 列分隔符：`!^`。
- 每行末尾使用 LF 换行。
- 空值输出空字符串。
- 文本值中的 CR、LF 和 `!^` 必须在写出前清理，确保下游解析不发生行列错位。

输出列按下列顺序：

1. 业务日期
2. 序号
3. 批次
4. 交易码
5. 交易名称
6. 问题级别
7. 登记日
8. 字段名
9. 问题描述
10. 交易负责人
11. 问题类型
12. 初步问题分析
13. 最终处理方案
14. 解决日期
15. 需协调
16. 解决人员
17. 流水号
18. 缺陷修复日期

其中：交易码、交易名称、问题描述、交易负责人和流水号按上述口径填充；其余整改字段及问题级别、登记日、字段名、问题类型均为空，待后续维护功能使用。

## 导出流水表

新增 `ana_tran_diff_tracking_export`，每条归一结果插入一行。表包含：

- 主键、导出批次时间、源批次号、业务日期、行序号。
- 归一键及服务码。
- 交易码、交易名称、领域。
- 528/CCBS 响应码和响应描述。
- 交易负责人和选取的流水号。
- 与导出列对应的整改字段：问题级别、登记日、字段名、问题描述、问题类型、初步问题分析、最终处理方案、解决日期、需协调、解决人员、缺陷修复日期；初始均为空。
- 创建时间、更新时间。

为 `(source_batch_id, service_code, orig_error_code, dest_error_code)` 建立索引，支持按源批次回溯；为 `export_timestamp` 建立索引，支持查询单次导出。

## 事务与错误处理

- 查询、写入导出流水表和生成文本在同一业务事务中执行。
- 数据库写入失败时终止下载，并回滚本次已写入的流水。
- 文本写入失败时抛出异常并回滚数据库写入。
- 仅在全部结果写入成功后向 HTTP 响应写出完整文本，避免客户端获得部分文件。

## 测试

- 控制器测试：批次缺失时拒绝导出；批次存在时返回正确的文本响应头和文件名。
- 查询测试：只按源批次过滤，并按服务码与双方响应码归一；同组只保留一条流水号和对应负责人。
- 导出测试：验证列头、`!^` 分隔、当前业务日期、空整改列、内容清理和文本行与落库记录 1:1 对应。
- 数据库脚本测试：验证新表、整改字段和索引存在。
