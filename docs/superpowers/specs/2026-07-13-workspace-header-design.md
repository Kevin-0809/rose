# Rose 工作区头部统一设计

## 目标

保留既有固定左侧菜单，在右侧工作区增加连续的顶部状态栏和页面头部，消除内容区顶部空白，并保持与深青色侧栏一致的视觉层次。

## 布局

1. 左侧导航继续作为独立固定栏，不改变一级/二级菜单结构、自动展开规则或移动端抽屉行为。
2. `workspace-bar` 显示产品名、当前页面路径、服务状态和当前日期；在窄屏仅保留菜单按钮与当前位置，避免信息拥挤。
3. 新增 `workspace-header` 位于状态栏与业务主内容之间，显示页面英文工作域、中文标题、简要说明和当前工作区名称。
4. 首页沿用其现有业务标题区，不额外重复首页标题；其他页面通过现有页面 `h1` 与 `eyebrow` 提供头部内容。

## 视觉

状态栏使用较深的蓝绿色底色和细分隔线，页面头部使用相邻深青色纯色层与现有内容背景衔接。状态、当前位置和标题分别使用绿色、灰蓝和浅色文字建立层级；不新增卡片阴影、大圆角或新的渐变。

## 实现与验证

在 `layout.html` 中扩展工作区栏并提供统一页面头部片段；各页面在 `main` 之前调用该片段并传入现有标题信息。`app.css` 添加头部样式与窄屏规则。模板测试覆盖头部片段与各页面调用，CSS 测试覆盖状态栏和页面头部规则。通过本地浏览器截图验证桌面与移动端无空白、无重叠。
