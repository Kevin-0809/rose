# 交易级二者都成功统计导出设计

## 目标

交易级导出 zip 中新增一个 UTF-8 文本文件，用于输出“二者都成功”的字段差异统计数据，满足 itoa 纯文本采集要求。

## 文件

新增文件名：

```text
transdiff_success_{yyyyMMddHHmm}.txt
```

该文件与现有 `transdiff_stat_*`、`transdiff_ccbs_*`、`transdiff_cbsp_*`、`transdiff_both_*` 一起放入交易级导出 zip。

文本字段分隔符使用：

```text
!
```

## 表头

```text
业务日期!批次!交易码!服务码!报文类型!成功数量!接口字段总数!比对字段总数!差异字段数!比对字段差异总数!单字段差异>=1%!单字段差异<1%!领域!责任人
```

## 统计口径

- 二者都成功：`tss_tran_comp.comp_result = '4'`。
- 聚合维度：`业务日期 + 批次 + 交易码 + 服务码 + 报文类型`。
- 成功数量：该聚合维度下二者都成功的交易流水数。
- 接口字段总数：从字段配置/映射表读取字段，按归一化后的字段名去重统计。
- 比对字段总数：`成功数量 * 接口字段总数`。
- 差异字段数：二者都成功交易下，字段差异按归一化字段名去重后的数量。
- 比对字段差异总数：二者都成功交易下的字段差异明细总次数，不去重。
- 单字段差异>=1%：按归一化字段名分组后，差异次数 `>= 成功数量 * 1%` 的字段个数。
- 单字段差异<1%：按归一化字段名分组后，差异次数 `< 成功数量 * 1%` 的字段个数。
- 领域：从交易配置表 `ana_tran_catalog.module_name` 带出。
- 责任人：从交易配置表 `ana_tran_catalog.owner` 带出。
- 如果同一聚合行匹配多个领域或责任人，去重后拼接。

## 字段归一化

所有字段统计都需要先归一化数组下标：去掉字段路径中的所有 `[数字]`。

示例：

```text
lst[0].acctNo -> lst.acctNo
lst[1].acctNo -> lst.acctNo
acctList[0].subList[1].amt -> acctList.subList.amt
```

归一化适用于：

- 接口字段总数。
- 差异字段数。
- 单字段差异>=1% / <1% 的分组统计。

字段名优先级：

1. 映射后的标准字段名 `std_field_name`。
2. `dest_field_name`。
3. `orig_field_name`。

## 实现边界

- 不新增页面入口。
- 不改变现有四个交易级 txt 文件名和内容口径。
- 新增文件随交易级导出 zip 一起下载。
- 继续保持大数据量友好，避免将全部明细一次性加载到内存。
