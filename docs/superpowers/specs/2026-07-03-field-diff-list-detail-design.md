# 字段差异列表与明细页设计

## 背景

当前字段差异页面使用宽表展示大量字段，表格最小宽度达到 2200px，用户需要横向滚动才能查看完整信息。长字段在列表中同时出现，导致页面扫描效率较低。

## 目标

- 字段差异列表优先展示主要信息，尽量不换行，不横向滚动。
- 列表中保留 SOAP 报文字段。
- 列表中不显示业务日期。
- 列表中不显示映射状态。
- 用户可通过双击行或点击“查看”链接进入该行明细。
- 明细页展示该行完整字段差异数据。

## 列表设计

字段差异列表仍使用表格，但改为摘要列表。表格宽度使用页面可用宽度，不再依赖超宽 `min-width`。

列表列：

- 批次号
- 交易码
- 服务码
- 报文类型
- SOAP 报文字段
- 字段中文名
- 样例流水号
- 528 值
- CCBS 值
- 责任人
- 影响交易笔数
- 操作：查看

列表行为：

- 所有单元格单行显示，超长内容省略，并保留 `title` 悬浮查看完整文本。
- 528 值、CCBS 值在列表中仅展示摘要，完整内容在明细页查看。
- 行支持双击跳转到明细页。
- “查看”链接提供显式入口，兼容不习惯双击操作的用户。

## 明细页设计

新增字段差异明细页，展示单条 `ana_field_diff_result` 的完整信息。

明细内容：

- 基础信息：业务日期、批次号、交易码、服务码、报文类型、责任人、影响交易笔数
- 字段信息：SOP 字段名、SOAP 字段名、BizJSON 字段名、字段中文名
- 状态信息：映射状态
- 样例信息：样例流水号、528 值、CCBS 值

明细页提供返回列表入口。返回时尽量保留原查询条件；如果实现成本过高，先返回字段差异列表默认页。

## 后端设计

在现有 `SampleQueryService` 中增加按字段差异结果 ID 查询单行的方法。控制器新增字段差异明细路由，例如：

`GET /samples/field-diffs/{resultId}`

若记录不存在，返回 404 或一个明确的错误页面，避免空白页。

## 测试设计

- 模板测试：字段差异列表包含 SOAP 报文字段，不包含映射状态列，包含查看入口和双击跳转数据。
- CSS 测试：字段差异表不再使用 2200px 超宽表；保留单行省略策略。
- 服务测试：按结果 ID 能查到字段差异明细，查不到时返回空。
- 控制器测试：明细路由能把记录放入模型并渲染明细模板。
